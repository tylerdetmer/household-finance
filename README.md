# Household Finance Tracker (iPhone PWA)

## Publish and install
This app needs an HTTPS website address before iPhone can install it. A straightforward free option is GitHub Pages:

1. Create a GitHub repository and upload every file in this folder to its root.
2. Open repository **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. When GitHub Pages provides the HTTPS address, open it in **Safari** on your iPhone.
5. Tap **Share → Add to Home Screen**. If shown, enable **Open as Web App**, then tap Add.

You can also use another static HTTPS host such as Netlify.

## Data privacy and backup
Transactions, budget edits and goals are stored in local browser storage on this device; the app does not connect to banks or upload data. Use Settings → Export backup (JSON) regularly. Import that backup to restore data. Clearing Safari website data can erase local app data.
